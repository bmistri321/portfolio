# Bishal Mistri — Product Designer Portfolio

Official portfolio website of **Bishal Mistri**, Product Designer specializing in user-centered digital experiences, B2B SaaS platforms, design systems, and product discovery.

🌐 **Live URL**: [https://portfolio.bishalmistri.com/](https://portfolio.bishalmistri.com/)

---

## 🚀 Features

- **⚡ Core Stack**: React 19, Vite, Vanilla CSS.
- **🎨 Design & Typography**: Clean aesthetic with Google Font `Google Sans Flex`.
- **📱 Responsive Layout**: Fluid responsive design across desktop, tablet, and mobile screens.
- **🧭 Floating Dock Navigation**: Custom bottom dock with active indicator and hover tooltips.
- **📂 Case Studies**:
  - **Friender AI B2B SaaS CRM**: 13-slide modular design flow with 0px gap gallery.
  - **Wexa AI Onboarding Redesign**: In-depth UX audit, heuristic evaluation, user journey, and solutions.
- **🖼️ Playground Gallery**: Masonry pin grid with custom circular hover zoom cursor and lightbox overlay.
- **📖 UX Design Mastery eBook**: Interactive download trigger with live download counter and 30-day curriculum table of contents.
- **🔍 SEO & Performance**: 100% compliant with single H1 hierarchy, JSON-LD Schema markup, XML sitemap, and robots.txt.

---

## 🛠️ Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/bmistri321/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```
